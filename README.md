# Dashboard для анализа продаж

Веб-дашборд для анализа заказов, клиентов, менеджеров и регионов.

## Возможности

- 📊 Аналитика по заказам, клиентам, менеджерам и регионам
- 📈 Интерактивные графики (Chart.js)
- 🔍 Фильтрация по региону, менеджеру, статусу, датам
- 📅 Отчеты по месяцам, неделям и дням
- 📥 Экспорт данных в XLSX
- 📱 Адаптивный дизайн

## Установка

```bash
npm install
```

## Запуск

```bash
npm start
# или
node server.js
```

Сервер запустится на `http://localhost:3000`

## Структура проекта

- `index.html` - основной файл дашборда
- `server.js` - HTTP сервер для раздачи файлов
- `xlsx_to_json.js` - скрипт для конвертации XLSX в JSON
- `clients_to_json.js` - скрипт для конвертации клиентов из XLSX в JSON

## Данные

Файлы с данными (`.xlsx` и `.json`) исключены из репозитория через `.gitignore`.
Для работы дашборда необходимы:
- `orders.json` - данные заказов
- `clients_all.json` - данные клиентов

## Использование ngrok для внешнего доступа

```bash
./start-ngrok.sh
# или
ngrok http 3000
```
